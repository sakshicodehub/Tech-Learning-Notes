Infrastructure as a Service

Problem it solves:
**"I need servers, storage and networking, but I don't want to buy physical hardware."**

**With IaaS, the cloud provider gives you the basic infrastructure.**

For example:

YOU
│
├── Your Application
├── Your Runtime
├── Your OS
│

☁️ CLOUD PROVIDER
├── Virtual Machine / Server
├── Storage
├── Networking
└── Physical Hardware

You are still responsible for quite a lot.

For example, you might rent a virtual machine from AWS.

You choose:

CPU
RAM
Disk
Operating system

Then you install and manage your software.

Example

Suppose you're building an e-commerce website.

You need a server.

> Instead of buying a physical server for ₹2 lakh, you rent a virtual server from a cloud provider and pay according to usage.

# IaaS solves:

> "Give me the infrastructure; I'll manage the software."

## Examples:

Amazon Web Services (AWS EC2)
Microsoft Azure Virtual Machines
Google Cloud Compute Engine
