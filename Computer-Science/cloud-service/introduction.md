# what problem did cloud computing solve?

Before cloud computing, if you wanted to run an application, you generally had to:

> Buy server → install OS → configure network → install database → maintain hardware → deploy application → handle backups/security/scaling

That created many problems:

Expensive hardware
Hardware maintenance
Need for IT/server expertise
Difficult to scale when users increase
Wasted capacity when users decrease
Long setup times

Cloud computing changed this idea:

**Instead of buying and maintaining computing infrastructure yourself, rent it from a cloud provider over the internet.**

Think of AWS, Microsoft Azure, and Google Cloud as companies that operate enormous data centers and rent their computing resources/services to you.
