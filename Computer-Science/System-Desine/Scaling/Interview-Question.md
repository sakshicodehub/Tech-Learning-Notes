 ### Very Common Interview Question

 **Interviewer:** _Your application is currently running on one server, but users are increasing. What would you do?_

 A simple answer:

 > **“I would first check whether the current server can handle the increased traffic. If possible, I can use vertical scaling by increasing CPU and RAM. If the traffic continues to increase, I would prefer horizontal scaling by adding multiple servers and using a load balancer to distribute requests between them.”**
